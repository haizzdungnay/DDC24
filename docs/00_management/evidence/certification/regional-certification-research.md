# Regional Certification Research — Block 4 Evidence

> **Source:** ResearchDirector web research, 2026-06-02
> **Methodology:** Lab websites + certification consultant portals + industry guides

## 1. Certification Requirements by Country

### 1.1 Vietnam — QCVN / CR Mark

| Item | Details |
|------|---------|
| **Regulatory Body** | MOST / STAMEQ |
| **Scheme** | CR Certification (QCVN conformity) |
| **Standards** | QCVN 4:2009/BKHCN (safety) + QCVN 9:2012/BKHCN (EMC) |
| **Lead Time** | 8-12 weeks (2-3 months) |
| **Cost** | USD 2,500-5,000 per product |
| **Certificate Validity** | 3 years (Method 1, with ISO 9001) |
| **Annual Surveillance** | 30-50% of initial cost |
| **Local Rep Required** | No (Vietnamese company = KINEXUS) |
| **Key Note** | QCVN 25:2025 new regulation (mandatory Apr 2027) for ≤440V devices |
| **Sources** | QUACERT, QUATEST, TUV Rheinland Vietnam portals |

### 1.2 Thailand — TISI / TIS Mark

| Item | Details |
|------|---------|
| **Regulatory Body** | Thai Industrial Standards Institute (TISI) |
| **Scheme** | TIS Certification |
| **Standards** | TIS 60335 series (aligned IEC) for electrical safety |
| **Lead Time** | 3-6 months |
| **Cost** | USD 2,100-3,900 per product (high-risk industrial) |
| **Certificate Validity** | 3 years (annual surveillance audit) |
| **Annual Surveillance** | ~USD 28-55 + audit costs |
| **Local Rep Required** | YES — Thai-registered company must hold certificate |
| **Sample Quantity** | 2-3 units |
| **Key Update** | e-TISI digital application system now active |
| **Sources** | TISI official, blueasialabs.com, cblueasia.com |

### 1.3 Malaysia — SIRIM / ST COA

| Item | Details |
|------|---------|
| **Regulatory Body** | SIRIM QAS |
| **Scheme** | ST COA (Certificate of Approval) |
| **Standards** | MS IEC 60730 (automatic electrical controls), MS IEC 60335 |
| **Lead Time** | 8-12 weeks standard; 4-6 weeks expedited |
| **Cost** | USD 7,000-21,000 (high complexity industrial equipment) |
| **Certificate Validity** | 5 years (COA), 1 year (ST COA) |
| **Annual Surveillance** | Factory audit ~USD 5,000-10,000/yr |
| **Local Rep Required** | YES — Malaysia-registered company mandatory |
| **Key Note** | CB/CE reports can reduce testing 30-50% |
| **Sources** | SIRIM QAS, blueasialabs.com |

### 1.4 Indonesia — SNI

| Item | Details |
|------|---------|
| **Regulatory Body** | BSN (National Standardization Agency) |
| **Scheme** | SNI Marking |
| **Standards** | SNI IEC 60730 (automatic controls), SNI IEC 60335 (safety) |
| **Lead Time** | 3-6 months |
| **Cost** | USD 5,000-15,000 |
| **Certificate Validity** | 4-5 years (annual surveillance) |
| **Annual Surveillance** | 30-50% of initial cost |
| **Local Rep Required** | YES — Indonesian registered company mandatory |
| **IECEE-CB Route** | Can shorten to ~45 days if CB-certified |
| **Key Update** | Ministry Regulation No. 7 & 9 (2025) — stricter enforcement |
| **Sources** | BSN, blueasialabs.com, huayutest.com.cn |

### 1.5 Philippines — PS Mark / ICC

| Item | Details |
|------|---------|
| **Regulatory Body** | BPS / DTI |
| **Scheme** | PS Mark (long-term) or ICC (per-shipment) |
| **Standards** | PNS (aligned IEC) |
| **Lead Time** | PS: 3-6 months; ICC: 2-4 weeks |
| **Cost** | PS: USD 2,000-5,000; ICC: USD 1,100-3,200/shipment |
| **Certificate Validity** | PS: 3 years; ICC: per shipment |
| **Annual Surveillance** | PS: annual factory audit |
| **Local Rep Required** | YES — Philippine importer/agent |
| **Key Note** | ICC sticker required per unit; AI label detection at customs |
| **Sources** | BPS/DTI, asiaecs.com, huayutest.com.cn |
