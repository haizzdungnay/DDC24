4. Radiated RF immunity — IEC 61000-4-3, Level 3: 10 V/m, 80-1000 MHz
5. EFT/Burst immunity — IEC 61000-4-4, Level 3: ±2kV power, ±1kV I/O
6. Surge immunity — IEC 61000-4-5, Level 3: ±2kV L-L, ±4kV L-PE
7. Conducted RF immunity — IEC 61000-4-6, Level 3: 10 Vrms, 0.15-80 MHz
8. Power freq. magnetic field — IEC 61000-4-8, Level 4: 30 A/m

Test Requirements:
- Number of rounds: 2 (Round 1: full compliance; Round 2: fix verification + re-test if needed)
- Sample quantity: 2 units per round

- Report format: ISO 17025 accredited test report
- Certification: CR Mark applicability if within scope
