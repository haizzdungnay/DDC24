# FBD EDIT Workspace Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `@source-command-subagent-driven-development` (recommended) or `@source-command-executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nâng bề mặt FBD `EDIT` thành workspace kéo-thả node-edge theo target PGM-02B, hỗ trợ desktop/tablet, nhưng giữ nguyên FBD schema/compiler/runtime và chỉ sửa FE.

**Architecture:** SVG-first trên `FbdDocument` + `fbdEditorReducer` hiện có. Canonical graph chỉ sống trong reducer/editor host; viewport, selection, preview và UI preferences là state tạm/local. Có thể chạy spike `@xyflow/react` ngoài bundle, nhưng chỉ chọn nó nếu qua toàn bộ gate license, adapter, a11y, performance và R1 bundle.

**Tech Stack:** React 18 + TypeScript, Vite, Tailwind token hiện có, SVG/Pointer Events, Vitest + Testing Library, Playwright + axe. Không thêm API/BE/Core/firmware trong plan này.

## 13. Rollback and stop rules

- **Cơ chế rollback bằng Feature Flag:** Mọi tính năng mới của FBD EDIT được bảo vệ bởi cờ `FBD_EDIT_ENABLED` / `VITE_FBD_EDIT` (tạo ở Task 2 trong `apps/web-ui/src/shared/config.ts`). Khi có bất kỳ sự cố nào trên môi trường kiểm thử hoặc production, chỉ cần tắt cờ (`VITE_FBD_EDIT=0`) để lập tức quay về giao diện FBD hiển thị cũ mà không cần revert commit hay viết lại dữ liệu Draft.
- **Hồi quy reducer:** Revert commit của task tương ứng trên nhánh `feat/fbd-edit` hoặc tắt cờ tính năng; không sửa đổi cấu trúc dữ liệu Draft trên backend.
- **Hồi quy layout/browser:** Vô hiệu hóa cờ FBD shell mới; preference cục bộ có thể xóa bằng cách xóa key `mkddc:fbd-preferences:v1:*`.
- **Nhu cầu contract/API/`variableId`:** Dừng lại, ghi nhận mã blocker/gate/điều kiện, và yêu cầu quyết định BE riêng biệt; không tự ý đoán endpoint hay thêm trường schema.
- **Cổng R1 / Performance / Trợ năng không đạt:** Dừng lại tại checkpoint tương ứng và báo cáo kết quả đo thật; không tự ý hạ tiêu chuẩn xuống R3 để che giấu nếu chưa có quyết định của Owner.
- **Thay đổi ngoài allowlist:** Dừng lại và hỏi ý kiến người dùng trước khi đụng vào đường dẫn đó.
